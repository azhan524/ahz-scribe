# Ahz Scribe 交付包说明（2026-10-18）

## 1. 可运行产物

| 产物 | 路径 | 说明 |
|---|---|---|
| 旧 .NET Framework 版 | `AhzScribe.exe` | 原栈，保留可回滚；启动不依赖 .NET 10 |
| 旧命令行版 | `ahzscribe-cli.exe` | 原栈命令行 |
| .NET 10 自包含版 | `dist/net10/AhzScribe.Net10.exe` | 不需要另装 .NET Desktop Runtime；CefSharp 154 |
| .NET 10 构建目录 | `migration/AhzScribe.Net10/bin/Release/net10.0-windows/win-x64/` | 开发/调试用 |
| 源码 | `src/AhzScribe.cs` | 单文件源码 |
| 复验报告 | `AHZScribe-修复复验-2026-10-18.md` | 逐项证据与残余 |

**旧栈 Scintilla 依赖**：`AhzScribe.exe` 旁边必须同时有 `Scintilla.NET.dll` 和
`packages\Scintilla.NET.5.3.2.9\build\x64\Scintilla.dll` / `Lexilla.dll`；
旧版加载器按 exe 目录找这个相对路径，缺了会启动失败。

- `config.json`：API Key 已 DPAPI（CurrentUser）加密；`.bak` 也是密文。
- `sessions.json`：12 条会话，历史 Key 已原地脱敏为 `[已脱敏]`。
- 脱敏前备份：`sessions.json.bak-20261018-153510.dpapi`（DPAPI CurrentUser，密文；明文备份已删除）。

## 3. 验证命令

一键全量验证：

```bat
cd local-agent
verify-all.cmd
```

它会依次跑：旧栈 build → 341/293/49/22 + 几何 → .NET 10 publish → 348 → ui_lint，全绿才返回 0。最新一次输出在 `_build/verify-all.log`。

当前结果：

```text
.NET Framework：341 + 293 + 49 + 22 + 几何 45 控件/0 越界
.NET 10：       348/348
build.cmd       UPDATED
ui_lint         96/100，0 FAIL
```

### CI

`.github/workflows/verify.yml` 在 `windows-latest` 上跑：旧栈 build、.NET 10 自测 348、publish、`ui_lint`。  
GUI 回归 `run-ui-tests.cmd` 需要交互式桌面，托管 runner 没有桌面，所以 CI 不跑；完整回归仍用本地 `verify-all.cmd`。

### 代码签名

`devtools\sign.cmd` 用 PFX 签 `AhzScribe.exe`、`ahzscribe-cli.exe`、`dist/net10/AhzScribe.Net10.exe`，并做 `signtool verify /pa`。  
它不会假装签名：没有证书时直接报“未设置 SIGN_PFX”并返回 2。证书需要你自己提供：

```bat
set SIGN_PFX=D:\certs\ahz.pfx
set SIGN_PASSWORD=***
devtools\sign.cmd
```

## 4. 回滚

1. 关闭程序；
2. 直接运行旧 `AhzScribe.exe`；
3. 需要恢复源码时用 `_build/rollback/20261018-audit-fix/` 里的改动前源码/browser-home/测试脚本；
4. 数据文件不要覆盖；如需恢复 Key 备份，用 DPAPI CurrentUser 解密，不要在明文状态长期保存。

## 5. 已知限制（2026-10-18 验收）

- Cef 首页暗色、`force-dark-mode`/`WebContentsForceDark` 已生效；WinForms `AutoScroll` 的原生滚动条仍浅色，**本版本不重做自绘滚动条**；
- 密码框当前不支持 IME 组合输入；后续单独排期：`WM_IME_*`、隔离合成缓冲区、候选中间串不写密码内存、多输入法兼容性测试；
- CI workflow 已就绪，但未在真实 GitHub runner 实跑（本版本不做）；
- 代码签名脚本就绪，未签真实证书；
- 旧栈只读区是**按行**拖选/复制，不是字符级；
- PerMonitorV2 已改成无缝重排，但只在消息级模拟，未做真实双显示器物理拖动验证。
