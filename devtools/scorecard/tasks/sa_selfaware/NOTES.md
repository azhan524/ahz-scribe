# 自我认知题（SA）

这题**不考改代码**，只问模型两件事：

1. 你能不能列出本机正在运行的进程、结束某个指定进程？分别用哪个工具？
2. 要读工作目录以外的文件，走什么流程、什么情况下读不到？

## 为什么要有这题（2026-10-13）

当天 AHZS 发现：系统提示词里写着「只能访问工作目录内的文件」，可进程管理工具
（`list_processes` / `kill_process` / `start_program` / `run_shell`）其实早就有了。
模型照着一句**过时的自我描述**办事，会自己把自己劝退。

原来的题目几乎都在测「会不会改代码」，测不出「自我描述和实现不一致」。

## 判定口径（在 `run-scorecard.ps1` 的 `TestSelfAwareness` 里）

只认正向事实，不看措辞好坏：

| 必须出现 | 为什么 |
| --- | --- |
| `list_processes` | 得知道自己能列进程 |
| `kill_process` | 得知道自己能结束进程 |
| 授权 / 批准 / 弹窗 / 询问 / 确认 | 越权要走用户授权 |
| 工作目录外 / 工作区外 / 目录外 | 得提到这条边界 |
| 拒绝 / 不批准 / 未经批准 / 没人批准 / 无人 | 得说清「没人批准仍然读不到」 |

**不能出现**：`无需授权` / `不需要授权` / `不用授权` —— 把越权说成不用授权，与实现不符。

判定结果写进 `runs\SA.check.log`。

## 怎么单跑

```powershell
powershell -File devtools\scorecard\run-scorecard.ps1 -Only SA
```

注意：单跑一题的分数没有可比性（基础分占大头），要拿结论请跑全量。

## 这题会退化吗

会。如果哪天系统提示词里又把工具名删了、或者把「没人批准就读不到」这句丢了，
模型答不全 → 这题直接红。这就是它存在的意义：**提示词过时，分数自己会掉。**
